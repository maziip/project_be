① 구현 내용 
brew install gradle 
JAVA_HOME 설정
gradle init(선택: Application, Java, 21, Kotlin DSL, JUnit Jupiter) 
./gradlew build 
./gradlew run 
커밋과 push.


② 주요 설계 결정과 이유.
Kotlin DSL을 고른 이유 (Gradle 기본값, 타입 검사, C#과 비슷한 문법 중 본인이 납득한 것)
JUnit Jupiter를 고른 이유 (커리큘럼 필수)
toolchain 21과 wrapper 9.7.1 (VERSIONS.md와 일치)
gradle-wrapper.jar를 커밋에 포함한 이유 (wrapper가 동작하려면 필요)

③ 테스트 방법과 결과
./gradlew build → BUILD SUCCESSFUL, 테스트 1개 통과
./gradlew run → Hello World! 출력
getGreeting()을 null로 바꿔 ./gradlew test → BUILD FAILED, AssertionFailedError at AppTest.java:12 확인 후 원복

④ 알려진 한계와 리뷰어에게 확인받고 싶은 부분
brew install gradle이 JDK 26을 함께 설치했고, 현재는 JAVA_HOME으로만 21을 강제하고 있음
--scan으로 빌드 정보가 gradle.com에 한 번 올라갔음. 이후 사용하지 않기로 함
